# Respuesta del Senado · 15-nov-2026

El Departamento de Información del Senado respondió a la solicitud de reutilización:

- **No existe** un conjunto de datos abiertos que permita descargar de forma conjunta y estructurada la composición de las comisiones: miembros, cargos y fechas de alta/baja.
- El Senado **está estudiando** incorporar esa información a su catálogo.
- No puede confirmar una vía de **descarga masiva documentada** ni **autorizar** el procedimiento automatizado solicitado; ambas cuestiones requieren revisión técnica.

## Impacto

- La composición de comisiones del **Senado no se ingiere** y no se estima.
- No se puede comparar la composición Congreso/Senado ni medir cargos del Senado.
- El microservicio mantiene **composición y actividad del Congreso**; del Senado solo se usa el listado público de leyes, no su composición.
- No se hará scraping ni acceso automatizado no autorizado.

## Decisión

Se actualiza el texto público: ya no se describe como un “bloqueo” técnico, sino como una **fuente inexistente o no autorizada**. Se revisará si el Senado publica el conjunto.
